⇅run: crane trolley carrying a plate (welder: chain hoist)
▤read: holding a blueprint
☀web: signal lamp blinking to the ship offshore, which answers
☛delegate: arms waving, lines running to each welder
…think: pacing, thought dots circling
⚒other: tapping a hammer

💡idle: floodlights low, crane still
